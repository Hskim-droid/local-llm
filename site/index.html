Get it

  1. 아래 복사를 누릅니다.
  2. 시작 메뉴에서 PowerShell을 열어 붙입니다. 관리자일 필요 없습니다.
  3. 바탕화면 local-llm 폴더가 열리면 시작.bat을 더블클릭합니다.
  1. Click Copy.
  2. Open PowerShell from Start and paste. Admin is not required.
  3. When the Desktop folder opens, double-click 시작.bat.
