local-llm

이 노트북에서만 돌아갑니다. 파일은 나가지 않습니다.

Runs only on this PC. Files do not leave the machine.

  1. 아래 복사를 누릅니다.
  2. 시작 메뉴에서 PowerShell을 열어 붙입니다. 관리자일 필요 없습니다.
  3. 끝나면 바탕화면 local-llm 폴더가 열립니다. 시작.bat을 더블클릭합니다.
  1. Click Copy below.
  2. Open PowerShell from the Start menu and paste. Admin is not required.
  3. A local-llm folder opens on the Desktop. Double-click 시작.bat.

      Windows가 “보호를 위해 실행을 차단”하면 추가 정보 → 실행.
      검은 창을 닫지 마세요. 첫 실행은 모델을 받습니다 (16GB는 약 5GB).
      파워셸이 막히면 zip을 받아 바탕화면에 푸세요. Source code가 아닙니다.
    

    

      If Windows blocks it: More info → Run anyway.
      Do not close the black window. First run downloads the model (about 5GB on 16GB PCs).
      If PowerShell is blocked, download the zip and extract it on the Desktop. Not Source code.
