# Security policy

This is an experimental, draft-first UI-to-document harness. It contains no
production ERP/QMS connector, sender credential, browser profile, or customer
data.

Never publish passwords, API keys, cookies, session files, real work records,
ERP/QMS URLs, mail credentials, or real-work screenshots in an issue, pull
request, commit, or fixture. Report a suspected vulnerability privately through
the [maintainer GitHub profile](https://github.com/Hskim-droid) rather than a
public issue. Revoke any exposed credential immediately.

A passing synthetic fixture does not certify real-host permissions, model
privacy, authentication, or unattended delivery.
