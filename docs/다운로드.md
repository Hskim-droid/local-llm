# 로컬LLM보고서 받는 법 (윈도우 그램)

컴퓨터에 익숙하지 않아도 됩니다. **압축을 풀고, 시작.bat을 누르는 것**이 전부입니다.

프로그램 파일은 약 7MB입니다. (AI 모델 5~9GB는 나중에 프로그램이 알아서 받습니다.)

---

## 제일 쉬운 방법 — 한 개의 압축 파일

1. 브라우저에서 이 주소를 엽니다.  
   **https://github.com/Hskim-droid/local-llm-report/releases/latest**
2. 페이지 아래 **Assets** 칸에서  
   **`local-llm-report-windows.zip`** 을 누릅니다.  
   (소스 코드 Source code zip 은 누르지 마세요. GitHub이 한글 파일 이름을 깨뜨려서 영어 이름으로 올려 두었습니다.)
3. 받은 파일을 **바탕화면**에 둡니다.
4. 압축 파일을 **우클릭 → 모두 추출**(또는 압축 풀기).  
   풀린 폴더가 바탕화면에 생깁니다.
5. **압축 파일 안을 더블클릭해서 실행하지 마세요.**  
   반드시 **푼 폴더** 안으로 들어갑니다.
6. 폴더 안에 이게 보이면 성공입니다.
   - `시작.bat`
   - `로컬LLM보고서.exe`
   - `읽어주세요.txt`
7. **`시작.bat` 을 더블클릭** 합니다.

Windows가 “보호를 위해 실행을 차단”하면:

1. **추가 정보** 를 누릅니다.
2. **실행** 을 누릅니다.

우리가 서명한 마이크로소프트 인증서가 없어서 뜨는 경고입니다. 파일을 인터넷으로 보내지 않는 프로그램입니다.

---

## 다른 방법 — GitHub 초록 버튼

릴리스가 안 보이면:

1. **https://github.com/Hskim-droid/local-llm-report**
2. 초록색 **Code** 버튼
3. **Download ZIP**
4. 압축을 푼 다음 **`dist` 폴더** 안으로 들어갑니다.
5. `시작.bat` 과 `로컬LLM보고서.exe` 가 같이 있는지 확인하고 `시작.bat` 을 누릅니다.
